**Cherry Studio**는 Gemini, GPT등의 다양한 AI 대형 언어 모델(LLM)을 하나의 플랫폼에서 통합 관리할 수 있는 **올인원 AI 데스크톱 클라이언트**입니다. 전문가부터 일반 사용자까지 누구나 쉽게 AI를 활용할 수 있도록 설계된 이 도구는 직관적인 인터페이스와 강력한 기능을 제공합니다.

설치 방법

1. Cherry studio 홈페이지에서 다운로드 https://www.cherry-ai.com/download
2. 우측 상단의 최근 다운로드 - cherry-studoi-setup폴더 열기
3. 설치 옵션,설치 위치 선택 후 설치

현재 JiminAPI는 Anthropic과 Open AI 두가지 형태의 API 방식을 제공하고 있습니다.

Anthropic모델 등록

Api키 등록

 1. Cherry studio 실행 후 우측 상단의 설정 버튼 클릭
 2. Model provider항목 선택
 3. Anthropic 선택
 4. API Key에 할당받은 Api키 입력
 5. API Host에 `https://api.jiminbox.com`입력
 6. Models 목록 우측의 -를 클릭해 현재등록된 모델 제거
 7. +Add클릭
 8. Model ID에 지원 모델을 입력후 add Model클릭 (주의: jiminAPI에서 제공하는 모델과 동일하게 입력해야 함.)
 9. API Key 우측의 Check박스 클릭
10. Connectoin Successful 확인 후 우측 상단 활성화 버튼 클릭

Open AI방식을 사용하는 모델 등록

Api키 등록

 1. Cherry studio 실행 후 우측 상단의 설정 버튼 클릭
 2. Model provider항목 선택
 3. New API 선택
 4. API Key에 할당받은 Api키 입력
 5. API Host에 `https://api.jiminbox.com`입력
 6. Manage클릭
 7. 우측의 +버튼을 눌러 원하는 모델을 추가
 8. API Key 우측의 Check박스 클릭
 9. 테스트할 모델을 선택후 OK버튼 클릭
10. Connectoin Successful 확인 후 우측 상단 활성화 버튼 클릭
