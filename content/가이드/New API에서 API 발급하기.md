
JiminAPI를 이용하기 위해서는 Jiminbox 계정을 이용해서 api key를 발급 받아야 합니다.

api key 발급받기 

1. [https://api.jiminbox.com](https://api.jiminbox.com/) 접속
2. 우측 상단에서 언어번경 - english
3. 우측 상단에서 sign in클릭
4. Continue with oidc클릭
5. jiminbox계정을 이용하여 로그인
6. 좌측의 Token Management클릭. 
7. create token클릭
8. 원하는 name설정
9. 권장: unlimited quota 활성화![[Pasted image 20260302135254.png]]
10. Submit 클릭
11. API key 발급확인

추가 정보: 
Quota settongs에서 이 api key가 사용할 사용량 제한 (Unlimited quota활성화시 할당받은 요금내에서 제한없이 사용가능)
Access Restrictions에서 이 API key에서 사용할 모델 설정(따로 설정하지 않을 시 모든 모델 사용가능)
