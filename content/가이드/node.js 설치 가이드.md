### 1. 다운로드 및 설치

1. **사이트 접속**
   - Node.js 공식 웹사이트에 접속합니다.
   - 링크: [https://nodejs.org/ko](https://nodejs.org/ko)

2. **다운로드 페이지 이동**
   - 메인 화면이나 메뉴에서 **'다운로드'** 또는 **'Get Node.js'** 버튼을 클릭합니다.
   ![[node.js 설치 가이드 사진1.png]]

3. **설치 파일 다운로드**
   - 운영체제(Windows 등)에 맞는 설치 프로그램을 선택합니다.
   - **'Windows Installer (.msi)'**를 선택하여 다운로드합니다.
   - *팁: 안정적인 사용을 원하시면 'LTS' 버전을, 최신 기능을 원하시면 'Current' 버전을 선택하세요. (Opencode 사용 시 최신 버전 권장)*

4. **설치 진행**
   - 다운로드 폴더에서 받은 `.msi` 파일을 실행합니다.
   - 설치 마법사의 안내에 따라 `Next`를 눌러 설치를 완료합니다. (기본 설정대로 진행하셔도 무방합니다.)

---

### 2. 설치 확인

Node.js가 정상적으로 설치되었는지 명령 프롬프트(CMD)에서 확인합니다.

1. **CMD 실행**
   - `Windows` 키 + `R`을 누르고 `cmd`를 입력하거나, 시작 메뉴에서 **명령 프롬프트**를 실행합니다.

2. **버전 확인 명령어 입력**
   - 아래 두 명령어를 각각 입력하여 버전 숫자가 나오는지 확인합니다.
     ```bat
     node -v
     npm -v
     ```

3. **결과 확인**
   - 아래 사진처럼 `v20.x.x`와 같은 버전 번호가 출력되면 성공적으로 설치된 것입니다.
